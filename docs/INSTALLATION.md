# Installing KeyClick

KeyClick plays soft keyboard sounds while you type.
It works with your normal keyboard. It does **not** record what you type.

---

## Windows (Windows 10 or 11)

1. Download **KeyClick-Setup.exe**
2. Double-click it.
3. Follow the installer.
4. Open KeyClick.
5. Choose a sound pack.
6. Turn KeyClick **ON**.
7. Start typing.

**Good to know**

- You do **not** need administrator rights. KeyClick installs just for you.
- KeyClick lives in the **system tray** (the small icons next to the clock).
  If you can't see it, click the **^** arrow next to the clock.
- Closing the KeyClick window does not quit it. To quit, right-click the tray icon → **Quit**.
- If Windows shows *"Windows protected your PC"*, the download is not signed yet.
  Click **More info → Run anyway** only if you downloaded KeyClick from the official website.

**To uninstall:** Settings → Apps → Installed apps → KeyClick → Uninstall.
Your settings are kept unless you tick *"Delete the application data"* in the uninstaller.

---

## macOS (Apple Silicon and Intel)

1. Download **KeyClick.dmg**
2. Open it.
3. Drag **KeyClick** to **Applications**.
4. Open KeyClick.
5. Grant keyboard monitoring permission.
6. Turn KeyClick **ON**.
7. Start typing.

**Giving permission (step 5)**

macOS asks you to allow apps that react to your keyboard.

1. In KeyClick, click **Open System Settings**.
2. Go to **Privacy & Security → Input Monitoring**.
3. Turn on **KeyClick**.
4. Go back to KeyClick. If it asks, click **Restart KeyClick**.

KeyClick uses this permission **only** to play a sound when a key is pressed.
It never records, saves or sends what you type.

**Good to know**

- KeyClick lives in the **menu bar** at the top of the screen (no Dock icon).
- Closing the window does not quit it. Click the menu-bar icon → **Quit KeyClick**.
- In password fields macOS hides key presses from all apps, so KeyClick is silent there. This is normal.

**To uninstall:** Quit KeyClick, then drag **KeyClick** from Applications to the Trash.
Optionally remove it from **Privacy & Security → Input Monitoring**.

---

## Start automatically

Open KeyClick → **Settings** → turn on
**Start KeyClick with Windows** / **Launch KeyClick at Login**.
It is off until you turn it on.
